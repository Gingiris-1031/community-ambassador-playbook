# Community & Ambassador Program Playbook — Full SOP

> Complete SOP for community building and ambassador program operations: pre-launch checklist, 6-step community setup, ambassador recruitment & tiered management, incentive design, event operations, content creation systems, health metrics, and governance. Built from Notion (20M users, real ambassador interviews), AFFiNE (60K GitHub stars), Asana Ambassador, and ClickUp Verified programs.

---

## 一、核心目标与价值主张

### 1.1 社区核心使命

| 维度 | 描述 |
|-|-|
| **核心目标** | 相互成就（Mutual Achievement） |
| **用户侧** | 通过品牌生态，帮助用户建立个人影响力，最终实现商业变现 |
| **产品侧** | 通过社区驱动产品全球扩张，形成用户-内容-产品的正向飞轮 |
| **社区运营理念** | 长期陪伴、共同成长，而非一次性流量收割 |

### 1.2 大使的本质：免费外包还是价值共创？

> ⚠️ 认知颠覆：大使计划的本质不是"招募粉丝"，而是构建一个**互利共赢的价值网络**。

| 维度 | 传统认知 | 真实本质 |
|-|-|-|
| **大使是什么** | 品牌宣传员 | 免费外包/CSM/经销商 |
| **激励来源** | 物质奖励 | 成为KOL的机会 + 创始人直接对话 + 定制化模板变现 |
| **官方动机** | 获取流量 | 降低人力成本、转移品牌风险、丰富User Case |
| **用户动机** | 为爱发电 | 工具好用 → 建立个人影响力 → 实现变现 |

**大使变现路径（Notion验证）：**

| 路径 | 说明 | 前提条件 |
|-|-|-|
| 定制化模板服务 | 靠用户基础 | 用户基数足够大 |
| 内容创作 | YouTube/博客教程流量变现 | 有内容生产能力 |
| 咨询/培训 | 行业解决方案服务 | 行业深度积累 |

## 二、大使项目启动的前置条件

> ⚠️ 重要提醒（Notion教训）：产品未达到可用状态之前，不建议正式推广大使计划。

### 2.1 启动 Checklist

| check | 条件 | 说明 |
|-|-|-|
| ☐ | 内部全员使用自家产品 | 商业化标准起步的真正信号 |
| ☐ | 产品已嵌入工作流 | 核心团队每天使用 |
| ☐ | 产品达到"可用"状态 | 最小用户闭环体验流畅 |
| ☐ | 有内容承载能力 | 已有可分享的模板、教程或案例 |
| ☐ | Roadmap可对外 | 能向大使透露路线图 |
| ☐ | 团队有专人负责 | Notion 2020年才招社区负责人 |

### 2.2 产品阶段判断框架

| 产品阶段 | 是否适合 | 策略 |
|-|-|-|
| 冷启动期（<PMF） | ❌ | 先找100个深度用户 |
| 成长期（PMF已过） | ⚠️ 谨慎 | 5-10名种子大使，免费、无考核 |
| 增长期（稳定增长） | ✅ | 正式大使计划，完整积分/晋升体系 |
| 成熟期（市场领先） | ✅ 全力 | 全生态网络，Affiliate分成 |

## 三、社区搭建 SOP（六步法）

### Step 1：确认社区定位与载体

| 载体 | 适用场景 | 优点 | 缺点 |
|-|-|-|-|
| 飞书/Lark | 内部协作+外部社区融合 | 与产品高度绑定 | 外部用户需注册 |
| Discord | 开发者社区、技术讨论 | 频道分类清晰，Bot生态丰富 | 需科学上网 |
| Slack | 国际化社区 | 频道组织成熟 | 企业用户为主 |
| Telegram | 实时讨论 | 触达快、管理简单 | 消息容易淹没 |

### Step 2：设定社区规则

### Step 3：确认管理员标准

| 职责维度 | 具体要求 | 运营指标 |
|-|-|-|
| 内容管理 | 每周至少3条新内容 | ≥3条/周 |
| 问答响应 | 24小时内回复 | ≤24小时 |
| 成员互动 | 主动邀请新成员 | ≥10人/周 |
| 规则维护 | 及时处理违规 | 处理率100% |

### Step 4：社媒舆情监测

> Notion的做法：**所有提到产品的账号都转推/关注**。做了爬虫自动监测所有Tweet。

| 监测对象 | 官方操作 | 目的 |
|-|-|-|
| 所有提到品牌名的账号 | 全部关注 + 转推 | 让每个创作者感受到被重视 |
| 发布品牌内容的普通用户 | 主动联系 + 邀请加入 | 转化为种子大使 |
| 竞品讨论 | 记录痛点 | 产品优化参考 |

> **关键洞察：普通用户持续产出 > KOL单次发布。**

### Step 5：建立知识库

### Step 6：设定基线指标

| 指标 | 种子期目标 | 增长期目标 |
|-|-|-|
| 社区成员数 | 50人 | 500人+ |
| 周活跃率 | ≥30% | ≥20% |
| 内容更新 | ≥3条/周 | 每日 |
| 响应时效 | ≤24小时 | ≤4小时 |

## 四、大使招募与管理体系

### 4.1 大使价值主张

| 价值类型 | Notion做法 | 通用建议 |
|-|-|-|
| 工具权益 | 免费Personal Pro + AI一年 | 官方账号Pro权限 |
| 活动支持 | $200/次活动 + $150打车费 | 按预算设置补贴 |
| 创始人对话 | Ivan 2019年亲自1V1见大使 | 定期Town Hall Q&A |
| 变现支持 | 帮大使在Fiverr/Upwork接单 | 官方推荐+品牌背书 |
| 职业背书 | 大使徽章 + 官方认证 | LinkedIn推荐信 |

### 4.2 准入标准（同时满足A+B）

| 类型 | 要求 |
|-|-|
| A：活动组织能力 | 线下连接、Meetup组织 |
| B：内容产出能力 | 视频/写作/模板（三选一） |

> 质量 > 数量：Notion大使名义数百人，活跃的只有25%。

### 4.3 分级与晋升体系

| 等级 | 条件（年度积分） | 核心权益 |
|-|-|-|
| Bronze | 申请即获 | 官方认可、徽章、资讯 |
| Silver | ≥100分/年 | 优先内测、官方转发 |
| Gold | ≥300分/年 | 1对1对接、年度活动 |
| Platinum | ≥600分/年 | 定制支持、大奖、赞助 |

**积分获取：**

| 贡献类型 | 积分 |
|-|-|
| Twitter帖子（@官方） | 5分/条 |
| 教程长文 | 20分/篇 |
| 视频 | 30分/个 |
| 社区回答（被采纳） | 3分/次 |
| Bug报告 | 10分/个 |
| 本地活动 | 50分/次 |
| 翻译文档 | 15分/页 |
| 邀请新用户 | 5分/人 |

### 4.4 流失预警

| 信号 | 应对 |
|-|-|
| 连续2月无贡献 | 私信关怀 |
| 内容质量下降 | 提供培训资源 |
| 感觉未被重视 | 安排1v1 + 转发内容 |
| 被竞品挖角 | 提供更多资源 |

## 五、大使赋能体系

### 5.1 新大使入职流程

| 阶段 | 时间 | 动作 |
|-|-|-|
| 申请审核 | 3个工作日内 | 审核表单，评估A+B |
| 欢迎邮件 | 审核通过后 | 大使手册+资源链接 |
| 社群导入 | 同期 | 加入大使专属频道 |
| 首次1v1 | 入职1周内 | 30分钟视频会 |
| Roadmap分享 | 1v1后 | 产品路线图 |
| 任务分配 | 1v1后 | 第一个任务 |
| 30天跟进 | 入职30天 | 贡献回顾+反馈 |

### 5.2 五大激励支柱（Notion真实洞察）

| # | 激励类型 | 说明 |
|-|-|-|
| 1 | 产品真的好 | 所有激励的前提 |
| 2 | Beta优先体验 | 感觉是"内部人" |
| 3 | 创始人直接对话 | 最高级别激励 |
| 4 | 帮大使成为KOL | 官方转发+Announce |
| 5 | 全部转推/关注 | 激励每个创作者 |

> ⚠️ 核心提醒：以上激励都建立在"产品真的好"前提上。产品不行一切免谈。

## 六、社区活动运营 SOP

### 6.1 活动类型

| 类型 | 规模 | 频率 | 目的 |
|-|-|-|-|
| 线上Workshop | 20-100人 | 月1-2次 | 产品教育 |
| AMA | 不限 | 季度1次 | 信任建立 |
| 用户案例分享 | 50-200人 | 月1次 | 社会证明 |
| 大使Seminar | 10-20人 | 周/双周 | 内部交流 |
| 本地Meetup | 10-50人 | 按需 | 地域深度连接 |
| 黑客松 | 不限 | 半年1次 | UGC产出 |

### 6.2 活动全流程

**筹备（前1月）→ 进行中 → 结束后（1周内）**

结束后必做：
1. 活动回顾发布（P0）
2. 反馈问卷（P0）
3. 长视频剪短视频（P1）
4. 参与者跟进入群（P1）

## 八、治理与风险控制

### 行为准则

**鼓励：** 真实分享（含批评）、帮助他人、注明利益关系、保护隐私、积极反馈

**禁止：** 代表品牌做承诺、发布虚假信息、未授权使用商标、攻击竞品、泄露机密

### 违规处理

| 级别 | 行为 | 处理 |
|-|-|-|
| 轻度 | 首次轻微违规 | 私下沟通 |
| 中度 | 重复违规 | 书面警告，暂停1月 |
| 重度 | 虚假信息/骚扰 | 即时取消资格 |
| 极度 | 违法/欺诈 | 取消资格+法律追诉 |

## 九、Notion大使案例核心洞察（10条）

1. 产品未可用之前，不要推广大使计划
2. 内部全员使用自家产品，才是商业化标准起步的真正信号
3. 大使本质是"免费外包"，但有价值观包装
4. Roadmap可以向大使公布（可画饼），但必须按时完成
5. 所有提到品牌的账号都应转推/关注
6. Notion做了爬虫自动监测所有品牌提及
7. 准入标准：同时满足 A（活动组织）+ B（内容产出）
8. 大使流失严重：名义数百人，活跃只有25%
9. 树立标杆：把做得好的专门Announce
10. 最强激励：创始人直接对话

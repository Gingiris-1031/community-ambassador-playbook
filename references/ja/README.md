## 一、コア目標とバリュープロポジション

| 次元 | 説明 |
|-|-|
| **コア目標** | 相互成就（Mutual Achievement） |
| **ユーザー側** | 個人の影響力構築を支援し、最終的にマネタイズを実現 |
| **プロダクト側** | コミュニティ駆動でプロダクトをグローバル展開、ユーザー→コンテンツ→プロダクトのフライホイール形成 |
| **運営理念** | 長期的な伴走と共同成長、一回きりのトラフィック刈り取りではない |

### アンバサダーの本質

| よくある認識 | 実態 |
|-|-|
| ブランドの宣伝担当 | 実質的な無償CSM/ディストリビューター |
| グッズがモチベーション | KOLへの成長パス + 創業者との直接対話 + マネタイズの道筋 |

## 四、アンバサダー採用と管理

### 4.1 資格基準（A＋Bの両方を満たすこと）

- **A：** イベント/活動の企画運営能力
- **B：** コンテンツ制作能力（動画/記事/テンプレート — いずれか1つ）

> 質 > 量：Notionのアンバサダーは名目上は数百人だが、実際にアクティブなのは25%のみ。

### 4.2 ティアシステム

| ティア | 条件 | コア特典 |
|-|-|-|
| Bronze | 応募・参加 | 認定+バッジ |
| Silver | ≥100pt/年 | ベータ優先アクセス+公式リシェア |
| Gold | ≥300pt/年 | 1対1アクセス+年次イベント |
| Platinum | ≥600pt/年 | カスタムサポート+大賞+スポンサーシップ |

### 4.3 ポイント獲得

| 貢献 | ポイント |
|-|-|
| Twitter投稿（@公式メンション） | 5 |
| チュートリアル/長文記事 | 20 |
| 動画コンテンツ | 30 |
| コミュニティ回答（採用済み） | 3 |
| バグレポート | 10 |
| ローカルミートアップ | 50 |
| ドキュメント翻訳 | 15 |
| 新規ユーザー紹介 | 5 |

### 4.4 離脱早期警告

| シグナル | 対応 |
|-|-|
| 2ヶ月間貢献なし | 個別DMでアウトリーチ |
| 品質低下 | トレーニングリソース提供 |
| 軽視されていると感じている | 1対1＋コンテンツをリシェア |
| 競合に引き抜かれそう | より多くのリソースを提供 |

## 九、Notionコアインサイト Top 10

1. プロダクトが使える状態になるまでアンバサダープログラムを宣伝しない
2. チーム全員のドッグフーディング = 商用化準備完了のシグナル
3. アンバサダーは本質的に「無償アウトソース」を価値観で包装したもの
4. ロードマップでビジョンは売れるが、必ず期限通りにデリバーすること
5. ブランドへの全ての言及をリツイート/フォロー
6. ブランド言及を自動監視するクローラーを構築
7. 資格：A（イベント企画）＋B（コンテンツ制作）両方必須
8. 名目上は数百人、実際にアクティブなのは25%のみ
9. ロールモデルを立てる → 他の人に方向性を示す
10. 最強のインセンティブ：創業者との直接対話

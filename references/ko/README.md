## 4. 앰배서더 모집 & 관리

### 4.1 자격 기준 (A + B 동시 충족)

- **A:** 이벤트/활동 기획 능력 보유
- **B:** 콘텐츠 제작 능력 (영상 / 글 / 템플릿 — 하나 이상)

> 양보다 질: Notion 앰배서더는 명목상 수백 명이지만 실제 활동 인원은 25%뿐.

### 4.2 등급 시스템

| 등급 | 조건 | 핵심 혜택 |
|-|-|-|
| Bronze | 지원 시 부여 | 인정 + 뱃지 |
| Silver | ≥100포인트/년 | 베타 우선 접근 + 공식 리쉐어 |
| Gold | ≥300포인트/년 | 1:1 접근 + 연간 이벤트 |
| Platinum | ≥600포인트/년 | 맞춤 지원 + 대상 + 스폰서십 |

### 4.3 포인트 획득

| 기여 | 포인트 |
|-|-|
| Twitter 게시 (@공식 멘션) | 5 |
| 튜토리얼/장문 아티클 | 20 |
| 영상 콘텐츠 | 30 |
| 커뮤니티 답변 (채택됨) | 3 |
| 버그 리포트 | 10 |
| 로컬 밋업 | 50 |
| 문서 번역 | 15 |
| 신규 유저 추천 | 5 |

### 4.4 이탈 조기 경고

| 시그널 | 대응 |
|-|-|
| 2개월간 기여 없음 | 개인 DM 아웃리치 |
| 품질 저하 | 트레이닝 리소스 제공 |
| 소외감 | 1:1 미팅 + 콘텐츠 리쉐어 |
| 경쟁사에 스카우트 | 더 많은 리소스 제공 |

| # | 기둥 | 설명 |
|-|-|-|

## 9. Notion 핵심 인사이트 Top 10

1. 프로덕트가 사용 가능한 상태가 될 때까지 앰배서더 프로그램 홍보 금지
2. 팀 전원 도그푸딩 = 상용화 준비 완료 시그널
3. 앰배서더 본질은 "무료 아웃소싱"을 가치관으로 포장한 것
4. 로드맵으로 비전은 팔 수 있지만 반드시 기한 내 딜리버
5. 브랜드 언급은 전부 리트윗/팔로우
6. 브랜드 언급 자동 모니터링 크롤러 구축
7. 자격: A(이벤트 기획) + B(콘텐츠 제작) 동시 충족 필수
8. 명목상 수백 명, 실제 활동은 25%만
9. 롤모델 세우기 → 다른 사람에게 방향 제시
10. 최강 인센티브: 파운더와의 직접 대화

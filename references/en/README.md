## 2. Pre-Launch Conditions

### Checklist (All Must Be True Before Starting)

| ☐ | Condition |
|-|-|
| ☐ | Everyone on the team dogfoods the product |
| ☐ | Product is embedded in internal workflows |
| ☐ | Product has reached "usable" state |
| ☐ | Content hosting capability exists |
| ☐ | Roadmap is shareable externally |
| ☐ | Dedicated team member is assigned |

### Product Stage Assessment

| Stage | Ready? | Strategy |
|-|-|-|
| Cold start (<PMF) | ❌ | Find 100 deep users first |
| Growth stage | ⚠️ | 5-10 seed ambassadors, no KPIs |
| Scale stage | ✅ | Formal program + points system |
| Mature stage | ✅✅ | Full ecosystem + Affiliate |

## 4. Ambassador Recruitment & Management

### 4.1 Qualification Criteria (Must Meet Both A + B)

- **A:** Demonstrated ability to organize events/activities
- **B:** Content creation capability (video / writing / templates — pick one)

> Quality > Quantity: Notion has hundreds of nominal ambassadors, but only 25% are truly active.

### 4.2 Tier System

| Tier | Requirements | Core Benefits |
|-|-|-|
| Bronze | Apply and join | Recognition + badge |
| Silver | ≥100 pts/year | Priority beta access + official reshares |
| Gold | ≥300 pts/year | 1:1 access + annual events |
| Platinum | ≥600 pts/year | Custom support + grand prizes + sponsorship |

### 4.3 Point Earning

| Contribution | Points |
|-|-|
| Twitter post (mentioning @official) | 5 |
| Tutorial/long-form article | 20 |
| Video content | 30 |
| Community answer (accepted) | 3 |
| Bug report | 10 |
| Local meetup | 50 |
| Documentation translation | 15 |
| New user referral | 5 |

### 4.4 Churn Early Warning

| Signal | Response |
|-|-|
| No contribution for 2 months | Personal DM outreach |
| Quality decline | Training resources |
| Feeling overlooked | 1:1 meeting + reshare their content |
| Being poached | Provide more resources |

## 5. Five Pillars of Incentive Design (Notion Insights)

| # | Pillar | Explanation |
|-|-|-|
| 1 | Product is genuinely great | Prerequisite for everything else |
| 2 | Beta priority access | "Insider" feeling |
| 3 | Direct founder conversation | The ultimate incentive |
| 4 | Help them become a KOL | Official reshares + announcements |
| 5 | Retweet everything | Encourages every creator |

> ⚠️ If the product isn't good, nothing else matters.

## 9. Notion Core Insights — Top 10

1. Don't promote the ambassador program until the product is usable
2. Internal team dogfooding = signal that commercialization is ready
3. Ambassadors are essentially "free outsourcing" wrapped in values
4. Roadmap can sell the vision but must deliver on time
5. Retweet/follow every brand mention
6. Build crawlers to auto-monitor brand mentions
7. Qualification: A (event organizing) + B (content creation) both required
8. Hundreds in name, only 25% truly active
9. Set role models → gives others clear direction
10. Strongest incentive: direct conversation with the founder
